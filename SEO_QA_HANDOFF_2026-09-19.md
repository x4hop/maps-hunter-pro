## Verified healthy behavior
- Root redirects to /en.
- www is attached to the same production Worker; Worker code redirects it 301 to the apex.
- Five localized homepage routes are served; Arabic is RTL.
- Language routing preserves query strings and hash anchors.
- Public UI uses SVG icons rather than emoji decoration.
- Wide Excel preview is intentionally inside an overflow-x:auto wrapper; mobile has no document-level horizontal overflow.
- robots.txt and sitemap.xml are served.
- Canonical/hreflang exist for homepage locales.
- JSON-LD includes WebSite, Organization and SoftwareApplication.
- Blog, Privacy and Terms routes return successfully.
- Admin uses restrictive security headers and is separate from public SEO routes.
